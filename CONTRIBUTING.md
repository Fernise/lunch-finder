# Contributing to Lunch Finder

Start with the README and the configuration guide. Open an issue describing a concrete problem, expected behavior and a minimal reproduction using fictional data.

Contributions are subject to the project’s MIT license.

Keep changes focused, preserve existing behavior and run the relevant documented checks. Add regression tests when fixing a meaningful behavioral or security bug. Never include credentials, personal records, private logs, real customer/learner data, database dumps or machine-specific paths in a patch or issue.

Use the Security tab’s private vulnerability reporting feature for security issues rather than a public issue. Automated checks do not authorize deployment, provider access or real messages.

## Development approach

This project uses AI-assisted development. The author sets the product and technical direction and is responsible for changes and their verification.
